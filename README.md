# Java Dog Register

A command-line dog registration system developed in Java as part of an introductory programming course at Stockholm University (2025).

## About the project

This application manages a register of dogs and their owners through a text-based interface.

The project focuses on object-oriented programming, data structures, sorting algorithms, and relationships between objects.

## Features

- Register and remove dogs
- Register and remove dog owners
- Assign dogs to owners
- Remove dogs from owners
- Increase a dog's age
- List registered dogs and owners
- Filter dogs by minimum tail length
- Sort dogs using comparators and a custom sorting algorithm

## Technologies and concepts

- Java
- Object-oriented programming (OOP)
- Classes and objects
- Encapsulation
- ArrayList and arrays
- Comparator and Comparable
- Selection sort
- Input validation

## How to run

Make sure Java JDK is installed.

1. Download or clone the repository.
2. Open a terminal in the project folder.
3. Compile the source files:

```bash
javac *.java
```

4. Run the application:

```bash
java DogRegister
```

The application runs in the terminal and accepts text commands.

Example commands:

- `register new dog`
- `register new owner`
- `give dog to owner`
- `list dogs`
- `list owners`
- `exit`

## Project background

This project was originally developed in 2025 as part of a university course in introductory Java programming.

It demonstrates foundational programming skills and the practical application of object-oriented design.
